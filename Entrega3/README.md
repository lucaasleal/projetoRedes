## Como executar
Abra o arquivo run.bat em um terminal windows:
```bash
./run.bat
```

Esse arquivo abre 4 terminais, sendo três clientes e um servidor.

OBS: Como o servidor não possui o diretório 'pasta', na primeira execução ele vai criar 'pasta', onde serão os arquivos recebidos. Em outras execuções, o diretório já existirá. Assim também para cada cliente ao executar um login pela primeira vez. Será criada um pasta "pasta_/_username_"
